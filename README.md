# Financial Dashboard (Power BI)

## 📊 Project Overview
An interactive Financial Dashboard built in Power BI to analyze company performance.
It provides executives and analysts with insights into Revenue, Profitability, Cash Flow, and Budget Variance, with filters for Month, Quarter, Product/Service, and Region.

## 🚀 Features
**KPIs at a glance:**
* Total Revenue: 3M
* Gross Margin %: 44.66
* EBITDA %: 25.42
* Net Cash: 83K

**Product/Service Performance:** Revenue distribution across products and services.

**Receivables Aging Analysis:** Track outstanding payments by region and aging category.

**Revenue & Profit Trend:** Compare quarterly revenue, gross profit, and EBITDA.

**Cash Flow Waterfall:** Visualize net cash changes year‑over‑year.

## 🛠️ Tech Stack
- **Power BI Desktop** – Data modeling, DAX measures, and visualization
- **SQL/MySQL** – Data integration and preprocessing
- **Excel/CSV** – Source data handling
- **GitHub** – Version control and project documentation
